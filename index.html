Casi listo. Falta conectar la base de datos.

  1. Crea un proyecto gratuito en console.firebase.google.com.
  2. Activa Authentication con Email/Contraseña y crea Firestore Database.
  3. Pega las reglas de firestore.rules.
  4. Copia la configuración web de tu proyecto en config.js y vuelve a subirlo.
